# Elfin Humble Workspace Documentation

Working documentation for the Elfin S20 luggage loading cell (ROS 2 Humble).

- `architecture/`: normative structure and data-pipeline rules; changes that
  contradict them are defects. Start at [architecture/README.md](architecture/README.md).
- `plans/`: active implementation and discussion plans. Index:
  [plans/README.md](plans/README.md).
- `research/`: bounded research notes (not production contracts).
- `hardware/`: current device references. Historical dual-machine YOLO notes
  are under `archive/hardware/`.
- `status/`: current validation records and evidence pointers.
- `agents/`: per-role session notes and the cross-CLI mailbox
  (`agents/discuss/OPEN.md`). See [agents/README.md](agents/README.md).
- `archive/`: completed or retired plans, status gate reports, and outdated
  context. Do not treat as current route.
- [CONTEXT.md](CONTEXT.md): short current-route orientation.
