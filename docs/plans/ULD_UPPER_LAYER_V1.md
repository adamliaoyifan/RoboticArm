## 1. 目标与明确约束

在有顶棚的 ULD 中增加一套与正常放置并行的 upper-layer place 动作。
复用已有 pick / offset pick。允许在柜外调整箱体角度，使 suction panel
朝上、位于箱体下方；先将箱体部分送入已有行李顶面，形成可释放的稳定支撑，
再释放吸盘、退出和调整机械臂，最后从后面直线推入目标位置。

第一版必须面向真实行李形成的起伏顶面，不能用理想水平板替代最终验收。
下层行李不得被主动整理、挪动、压平；不增加翻滚、越障或拨开行李的动作。
不满足支撑、退出、推入或观测条件时拒绝该候选。支持起伏表面不等于承诺任意
起伏均能成功；必须给出支持范围和范围外拒绝原因。

无触觉传感器。保留两个独立评估配置：A 为 RGB-D/已有几何传感器和关节位置；
B 额外允许已验证可用的原生关节电流或力矩反馈。B 的结果不能代替 A 的验收。
D555i 沿用仓库 D555 感知链命名；具体硬件型号、安装和标定在实测前核对。

本次只保存计划并清理工作树资料，不开发功能、不启动仿真或真实机械臂。
原有离线原型保留为研究工具；它没有验证完整手臂连续轨迹或接触物理，不能作为
本计划已完成的证据。此前 G1 的冻结范围和结果由 Git 历史及主工作区记录保存。

## 2. 何时使用上层动作

在 COMPUTE_PLACEMENT 阶段、EXEC_PICK 之前联合选择：
`(目标位姿, 抓取接触位置/偏置, 动作类型)`。

1. 获取同一 geometry_hash / map_revision 下的目标空间与局部支撑快照。
2. 生成几何放置候选；不提前用旧的吸盘朝下动作限制筛掉全部上层候选。
3. 分别评估 normal-place 与 upper-layer-place。正常动作可行时第一版优先正常动作。
4. 正常动作不可行、且上层动作的支撑、完整轨迹、推入和可观测性检查通过，才选择上层动作。
5. 数据不足返回 NEED_OBSERVATION，由已有观察流程补观测；两类动作都无可执行候选则报告原因。

装载比例、层号、一次规划超时或 BIN_FULL 都不能单独触发上层动作。
已经抓取时必须采用实际 tool-to-box 变换重新评估；不能假定能在空中更换抓取偏置。
需要重新抓取时走显式恢复流程，不隐含增加动作。

## 3. 感知与 planner 的职责

结论：保留相机底层链路，补充局部场景表达和可观测性；仅修改 planner 不足。
现有最高占据高度和箱体检测不能完整描述支撑接触区、空洞、台阶和工具退出通道。

| 层级 | 拟新增或复用 | 输入 → 输出 | 责任边界 |
|---|---|---|---|
| 相机链路 | 复用同步 RGB、对齐深度、CameraInfo、预处理状态 | 同次采集数据 → 合法观测 | 不新增第二套同步，不绕过 canonical preprocessor |
| 地图 | 复用 cargo_volume_mapper；必要时增加只读 ROI 快照接口 | ROI、预期版本 → occupied/free/unknown、来源和版本 | 地图仍由现有模块唯一维护 |
| 局部支撑几何 | 新增 local_support_geometry.py | 场景快照 → 表面样本、法向、区域、边缘、台阶、缺口和质量 | 不判断力学承载能力，不输出最终 can_place |
| 候选生成 | 新增 upper_layer_candidates.py | 局部几何、箱体、合法抓取、质心范围 → 候选 | 负责箱体相关的接触和几何约束 |
| 动作规划 | 新增 upper_layer_motion_planner.py | 候选、机器人模型 → 连续轨迹或拒绝原因 | 完整机械臂、末端、箱体及阶段接触约束 |
| 下层运动监测 | 新增 support_motion_monitor.py | 基线和新观测 → 运动证据及可观测状态 | 不把看不见误报为静止 |
| 编排 | 扩展现有动作选择/执行流程 | 动作结果 → 继续、补观测、停止或恢复 | 感知查询不得自行驱动机器人 |

优先实现 ROS-free 纯函数 `extract_support_geometry(snapshot, roi, config)`。
监测器需要历史状态时使用 `update(data, stamp, frame_id)` / `copy_output()`，
返回独立副本。ROS 节点只承担消息、TF、服务与生命周期适配，不继续扩张大节点。
已有 top_support_estimator / dynamic_top_surface 的通用几何可以复用，
但不能将整个多行李支撑面拟合成单一平面。现有单箱 tracker 不能直接证明多箱静止。

## 4. 接口草案

先定义进程内类型；实现前检查分支已有查询能力，避免重复接口。
只有跨进程确有需要时才在 luggage_msgs 增加消息或服务。

`LocalSupportSnapshot` 至少包含：

- snapshot_id、frame_id、geometry_hash、map_revision；各视图采集时间及新鲜度。
- ROI、实际分辨率、表面采样/局部网格、法向、连通区域、边界、台阶和缺口。
- 有效掩码、覆盖率、观测来源、质量信息与可追溯的不确定性估计。
- 同一快照的局部 occupied/free/unknown 数据或稳定的只读查询句柄。
- 几何顶棚距离与已观测自由空间分别表达，不能用前者代替后者。

可选服务草案：`GetLocalSupportGeometry(roi, expected_revision, geometry_hash)`
返回快照、实际版本、valid、reason。版本不一致、数据过期或空间未知均显式返回。
细化栅格不能自动提升深度精度；平面残差不能直接当成距离误差界。
未分类的障碍物仍必须进入碰撞检查。

`UpperLayerCandidate` 包含 final_box_pose、handoff_box_pose、push_direction、
合法 suction_contact / tool_to_box、临时和最终接触区域、支撑假设、退出/重定位通道、
snapshot_id，以及各检查状态。最终位姿、临时承托位姿与推入路径不能只用一个 SlotSpec 表达。
保持 DetectedLuggage 描述待抓箱体，不向其中塞入目标行李堆地形。

`SupportMotionObservation` 输出 `MOTION_DETECTED`、`NO_MOTION_OBSERVED` 或
`NOT_OBSERVABLE`，并提供区域、时间、位移估计、误差和覆盖率。
基于原始/近期观测、时间对齐和相机运动补偿，屏蔽机械臂及目标箱体；不能仅比较平滑地图。
panel 朝上和推入时必须检查实际视野。相机遮挡不能靠新增 class 消除。

## 5. 动作与失败边界

阶段：柜外翻转 → 向上承托接近 → 部分插入 → 稳定承托检查 → 释放 →
向下/向外退出 → 连续调整到后侧 → 低速直线推入 → 最终复测。
每个阶段明确允许接触的对象及面，其他接触仍为碰撞；不得为解决卡住放开整箱碰撞。
检查完整手臂、吸盘、转接件、相机、雷达和负载的扫掠体，包括姿态切换。
阶段 IK 存在不能证明阶段之间连通。

临时承托不是“插入一半”固定比例。依据真实抓取位置、箱体质心包络、有效接触区和
抗倾覆余量求可行区间，同时保留吸盘退出空间。起伏接触可能使箱体倾斜，必须检查
倾斜后顶棚间隙和后续直推路径；需要越过台阶或重新摆正才可推入的候选在 V1 拒绝。

RGB-D 不能直接给出重量、内部质心、摩擦、软箱变形、承载能力和吸盘抗剥离能力。
必须定义这些参数的可验证范围，并进行范围内鲁棒检查，不能从点云编造力学参数。
只有视觉的配置不能声称具备力控或保证接触力；停止延迟及可检测位移限制必须实测。

发现下层移动、失去关键观测、目标滑落趋势、版本失效或执行异常时停止推进并进入
阶段相关恢复。释放前保持真空；释放后不能假设仍附着，恢复策略必须单独验证。
不得自动重复推入或通过更大推力完成动作。

## 6. 分阶段实施与验收设计

以下是设计阶段的工作划分，尚未派发。各阶段由同一实施责任人完成代码、测试、修复和记录；
派发时补齐具体 owner/model、精确 plan_revision、代码基线和命令。当前不使用未存在的测试命令假装可运行。

| 阶段 | 工作 | 必须观察到的结果 |
|---|---|---|
| P0 参数与测量 | 核对资产、标定、载荷范围、可见性和反馈能力；固定评价配置 | 每个阈值有来源/测量方法，观测误差和停止延迟已测，两个传感器配置独立 |
| P1 感知离线回放 | 局部快照、几何提取、下层运动监测 | 时间/版本错误与 unknown 被拒绝；缺口和台阶保留；运动与不可观测明确区分 |
| P2 候选与完整轨迹 | 联合抓取、交接、退出、后推规划 | 有效轨迹覆盖全部阶段；拒绝碰撞和不稳定候选；正常放置不回归 |
| P3 仿真物理 | 起伏多行李、顶棚、真实末端，先固定几何后传感器闭环 | 下层可自由运动，动作成功不能来自锁定支撑；GT 仅用于造场景和评分 |
| P4 受控实物 | 在锁定的材料/重量/质心/摩擦范围内验证 | 校验仿真偏差和传感器配置限制，达到冻结的位移、成功率和停止阈值 |
| P5 集成 | 选择、执行、异常恢复与原有 pick/offset pick 回归 | 只有完整可执行候选才触发上层动作，异常可追溯，不偷偷添加整理动作 |

P1/P2 的确定性契约案例每项至少一个正例和一个独立构造反例，全部通过；
它们证明契约行为，不用于宣称现场成功率。对未采集到的测量项输出 not_evaluated。

P3 必须先建设专用场景。至少覆盖：均匀顶面作对照、不同高度错位箱体、横向坡度、
推入方向台阶、跨缝支撑、可变形表面、低摩擦可滑支撑、可滚动/不稳定支撑、
顶棚过低、退出通道不足、遮挡/深度缺失、地图版本改变。
将预期可执行与预期拒绝分开；不能靠全部拒绝通过验收。

矩阵另外交叉箱体尺寸、合法中心/偏置抓取、允许质心包络、顶棚间隙与 A/B 配置。
具体数值及削减组合必须在 P0 形成固定 manifest；不要直接继承 G1 的理想平面阈值。
先进行可重复的非计分接线/启动演练，再冻结场景、随机种子、模型、命令和代码 hash 评分。
计分中不得修改被认证产物；启动前失败不消耗场景种子，但记录发生率和耗时。

## 7. 派发前必须冻结的验收表

“下层行李不动”是需求；有限精度测量只能报告位移上界，不能宣称数学意义零运动。
当前不擅自替用户把 5 mm 或其他容差视为已接受。下表是 dispatch_ready=no 的具体原因。

| 指标/参数 | 冻结方法和必须记录的字段 |
|---|---|
| 下层位移与转角 | 每件支撑行李从接触前至结束的最大平移/转角及测量误差；允许上界需明确，不能只比较最终位置 |
| 可观测性 | 各动作阶段的可见覆盖、深度有效率、最长盲区、新鲜度限值、低于限值的停止行为 |
| 几何误差/余量 | 标定与深度误差、栅格尺寸、碰撞裕度、交接支撑裕度和倾角限制；误差必须小于对应决策余量 |
| 接触范围 | 重量、质心包络、材料、摩擦/柔顺性范围、吸盘负载范围，以及 A/B 各自停止速度和距离 |
| 完成质量 | 最终位姿误差、稳定时间、超时、允许接触及禁止事件；箱体全部进入目标容积 |
| 可靠性 | 每个场景族与传感器配置的目标单次成功率、重复数、随机种子、置信界和聚合规则 |
| 拒绝能力 | 无效候选误接受率、有效候选误拒绝率和最小有效样本数；分场景报告，不能只看总体平均 |
| 性能 | 分阶段延迟、停止响应和最大执行时间，明确硬件与软件环境 |

可靠性采用每个配置/场景族分别统计的二项成功率置信界，目标和样本数先冻结。
若使用连续 N 次全过，必须说明其通过概率为 p^N，验证门槛能区分可接受与不可接受的
单次成功率；不得把大量样本全部通过当成随意指定的质量指标。缺少最小样本时结果为
not_evaluated，不能按零失败计成功。危险事件与感知/规划失败分别报告。

尚待确定：实际重量/质心先验来源；原生力矩反馈可用性；下层位移的可接受测量界；
不同姿态下相机是否能持续看见支撑；最小有用的可执行起伏场景范围。
这些信息决定实现与验收范围，不能用 planner 参数默认值替代。

## 10. 已授权先行项：对齐密铺仿真场景（2026-11-11）

此项可以独立执行，不代表前述动作算法或产品验收已具备派发条件。
Owner: eng/codex/gpt-6；基线为本文件 base_revision；使用当前 worktree，保留既有资料清理。
新增研究场景生成器及必要的通用 world_sdf 启动参数，不实现自动放置或改动 pick。

固定场景使用原始场景的 ULD 网格、位姿和七面体内轮廓。4 层、每层 3 个深度列和
2 个宽度行，共 24 个对齐的独立动力学箱体；侧面按 chamfer 收缩底层尺寸。
测试载荷使用 carryon 行的 0.55 × 0.40 × 0.25 m；上层余量为箱高加 0.03 m，
期望支撑面 z=1.73 m、可用顶层高度 0.28 m。合成下层箱体不是新增的实物尺寸先验。
保留正常机器人、传感器、平台与箱体生成服务；默认不发任何机械臂运动命令。

验收为一次确定性场景构建和一次 5 s 仿真时间的无外力稳定性检查：
所有箱体完整包含于规范 hull，无互穿；顶层平齐；顶部净空满足箱体而不足以容纳
吸盘朝下的完整固定末端；按 hull 裁剪的底部填充率至少 90%；下层无 static/fixed joint。
物理检查中相对初始位姿最大水平位移 ≤ 0.003 m、竖直沉降 ≤ 0.010 m、姿态角 ≤ 0.01 rad；
这只验场景搭建和重力稳定性，不证明推入时下层不动或动作成功率。
同时做完整栈启动演练：S20 生成且 arm_controller active；不评分运动/感知表现。

`python3 research/uld_upper_layer/scene.py --output /tmp/uld_upper_layer_scene`，
