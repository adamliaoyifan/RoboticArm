## Scope

统一部署分辨率配置默认0.01m，OCC XYZ与高程XY同值；显式启动覆盖0.05/0.02可用。运行时参数只读，mapper resolution只读，store唯一产品写入口。allocation前校验有限正数/尺寸及8M voxel上限；部署分辨率范围0.005..0.05，纯算法允许旧测试的小体积粗网格。去除独立floor prior默认来源，launch参数显式同喂；默认来自统一配置加载路径。必要的1cm性能优化必须保持旧网格逐cell语义，包括geometry锁、sensor shadow、unknown和inactive。

## Acceptance

1. 全部新增参数/权限/网格行为测试及相关现有mapper/store/栅格化/logodds测试通过。读副本修改不影响store，非法参数拒绝不改状态；同store snapshot resolution与volume一致。运行Node参数测试不启动Gazebo。
2. 对同一输入在0.05/0.02/0.01比较：合成矩形yaw0/5/45/90°，网格相位0/0.25/0.5/0.75（以5cm作为固定世界位移基准），2cm箱间缝，约20cm厚箱体；另重建已保存5箱**测量**ledger布局（derived fixture，非原始感知回放）。每例各跑一次确定性oracle核对，ALL通过；不作成功率统计。
3. 独立几何oracle检查所有正体积交叠active voxel：漏占用=0、越oracle占用=0；surface与3D最高占用投影不一致=0；box内部无支撑孔洞。真实缝隙和外部unknown独立计数，不把unknown自动free，不把2cm缝填成箱顶。量化top误差范围[0,resolution]加1e-9；输出边界保守扩展面积和gap保留率，对比不同分辨率，不要求每个旋转情形严格单调。
4. 原5cm实现对同输入输出作为baseline：优化后5cm states/active/surface/ledger等价（计时、随机epoch除外）。捕获基线再改算法，保留原始输出hash。
5. 同部署主机实尺寸1.49x1.97x1.48，1cm4,344,244voxels；构建+首次snapshot<=30s，peak RSS<=2GiB；5箱更新+surface/digest 3预热/30测量p95<=1s/max<=2s。缺30样本not_evaluated，未达门先优化再验。只量测mapper，planner cost/整场性能不属于S1结论。
