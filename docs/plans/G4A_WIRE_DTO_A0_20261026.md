## 模块与职责（全部纯模块，无 ROS import）

1. `luggage_perception/cargo_query_wire.py` —— QueryWireCodec：
   - `WIRE_SCHEMA_VERSION = 1`。
   - **对象编码**（内容寻址 `objects/<sha256>`，逐对象自描述头）：
     - 数组对象：`magic|dtype|ndim|shape…|raw bytes`（小端原生序，dtype
       白名单：u1/i4/i8/f8/u2/<u2 结构按其简单成分拆分）；>4MiB 分块
       （`|chunk idx|chunks total` 头），manifest 记每块摘要。
     - JSON 对象：规范 JSON（键排序、`separators=(',',':')`、UTF-8、
       顶层类型标注），用于 members 映射/summary/provenance/元数据。
   - **manifest**（`generations/<incarnation>/<seq>/manifest.json`）：
     producer_incarnation(UUID)、map_epoch、seq、kind(FULL/DELTA)、
     base（完整5腿身份+base manifest sha256，FULL 为 null）、target
     完整身份、geometry_hash、grid{shape,origin,resolution,frame,
     geometry_hash}、commit_monotonic_ns、entries{name→{type,bytes,
     shape,dtype,sha256,chunk}}、deletes[]、distance_recipe_version、
     自身规范化 checksum（对除 checksum 字段外的规范 JSON 取 sha256）。
   - 禁 pickle/eval/任意反序列化；所有长度先验上限再分配；数组 dtype/
     shape 白名单校验；路径仅受控相对名。
2. `luggage_perception/cargo_query_export.py` —— QueryExportPublisher：
   - `offer_committed(snapshot, dirty_blocks, provenance_changed)`：
     只读源数据；FULL/DELTA 决策（无 published→FULL；否则 DELTA）；
     未变对象按内容地址引用不重写；写 objects→写 manifest→校验→
     原子 rename `published.json`+`head.json`。
   - 有界队列：pending ≤2、staging ≤1、已发布可读代 ≤2；越限
     `EXPORT_BACKLOG_FULL`（阻塞新发布不丢代，记录未发布 seq 区间）。
   - 生命周期：`start/stop`；export 异常=具名状态绝不吞成成功。
3. `luggage_perception/cargo_query_replica.py` —— QueryReplica：
   - `poll()`：读 head/published→序号/epoch/incarnation 校验→载入
     manifest→按需取对象（校验 sha256/长度后分配）→DELTA 验 base→
     **重建 QuerySnapshotData**（深不可变）→ 校验 target 身份 →
     `apply_complete` 原子换 registry；坏 hash/缺块/错 base/未知
     schema→RESYNC_REQUIRED。
   - 派生字段重建：distance 材料按 `freeze_distance_members` 确定性
     重建（recipe 版本入 manifest，逐字段 oracle 验证）；identity
     root 由接收端用与 `freeze_query` 相同的纯哈希函数重算比对
     （该哈希链抽为共享纯函数，原调用点行为不变——兼容测试覆盖）。
   - token/cursor 密钥：replica 会话内自建且稳定；重启即换（协议 §5）。

## A1 验收（本单元第一组门，协议 A1/A2 条款）

- 三分辨率×两 hull×0/5/20 箱，seed0..9 各 100 更新：FULL 重建与源
  快照**全公开字段/身份逐字段全等**；DELTA 链终态与 FULL 终态全等。
- 增量边界（各3重复）：跨块 frontier-only（邻块 digest 不变）、
  label/instance-only、零 cell 确认态、shadow/remove、overlap、
  partial block、reset。
- 未变对象不重写（内容地址命中断言）；无 pickle；接收端零可写别名
  （deep-frozen 断言）；源主事实不变（写前后 mapper 主数组字节相等）。
