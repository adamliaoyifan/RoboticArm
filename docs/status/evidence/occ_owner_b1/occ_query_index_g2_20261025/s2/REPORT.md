# S2 block/instance/immutable query checkpoint

S2 extends the S1 derived owner; product baseline remains user-adopted b33dda91, dispatch plan b9f4b2dc. Only query/index/observation hooks changed. Primary storage, clipping, rays, fusion, shadow, revisions, commit acceptance and planning remain unchanged.

Implemented schema-1 GridInfo/QueryIdentity/CellKey/InstanceKey/QueryPage and frozen result DTOs. Store acquire_query_snapshot selects the published generation. Core methods: summary, get_cell, query_cells, query_frontiers, count_frontiers, query_instance. Typed ROS, incremental surface and distances remain S3-S5 work.

Indexes use 16-cube blocks, compact immutable cell evidence and per-block state/frontier/member summaries. Canonical full evidence is retained only by the owner for incremental voxel hashes. Queries share unchanged COW blocks and never reference primary arrays. Legacy digest is unchanged; voxel digest binds all live/shadow/lock evidence, geometry membership and omitted publication provenance.

Real box_id is bound only on an actually added existing commit; geometry raster membership is captured at its existing boundary, not regenerated by a new occupancy rule. Overlap retains both box memberships. Missing/ambiguous binding returns INSTANCE_BINDING_MISSING; sensor instance keys explicitly require legacy:<epoch>. Removed known IDs return a complete empty result.

Region intersection is positive-volume and pages use stable flat index ordering. Cursors HMAC-bind full identity and query parameters. Handles expire after five monotonic seconds or when an epoch/third generation retires them; explicit close releases sessions. Registry admits at most 128 sessions and two generations, with conservative 512MiB accounting. Resource refusal closes new sessions, preserves admitted old data and does not discard physical facts. Existing legacy snapshot/summary and query generation publish under the short registry lock. No write-transaction lock is taken by query methods.

## Demonstrated

- 91 tests + 2 subtests passed on the final compact representation (unit_tests.log).
- Three resolutions: random ROI pages match independent scalar intersection; frontier pages match full legacy predicate in new flat order, with no missing/duplicate cells.
- Real box memberships match original raster indices including overlap/removal. Sensor reverse index follows latest shadow after geometry removal; an instance query visits only its matching block.
- Tests cover 15/16/17 seams, inactive holes, immutable byte backing, query tampering, identity mismatch, expiry/reset/close, explicit session/memory refusal, and stable COW old snapshots.
- Two readers + one writer, 1,000 accepted Store transactions x three repeats: page and summary stay on one matching bundle; completed observations correspond to writer-published identities. Named expiry is allowed in this accelerated correctness stress; it is not the fixed-rate ROS heartbeat acceptance workload.
- Preliminary isolated 10,000-transaction replay matched b33 exactly; post-commit replay is recorded separately.

## Acceptance boundaries

S2 implementation checkpoint, not S2/G2 overall PASS. Full requested small/large maps, 0/5/20 actual boxes x hulls x resolutions, formal 3+30 sample timings, installed ROS/serialization, write regression, 120s x3 heartbeat stress, resource peaks and placement outputs remain mandatory and not_evaluated. Precompact resource observations are explicitly unscored development diagnostics. Missing-hash test-fixture refusal and replay are preserved under failures/.
