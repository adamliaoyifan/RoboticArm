## 新事实：运动包络（sim 时戳，|v|>0.005 连续段）

- **生产**：腿 119.1→342.5（**跨 goal 末端 295.8 后仍持续 46.7s**），
  其后 343.5–354.8 / 356.1–368.3 / 369.7–410.8 / 411.9–446.2 四段——
  **driver 已于 sim≈370 被 SIGKILL，369.7 后的运动无 driver 进程参与**：
  reference 冻结下的自持对象侧运动（缓爬/间歇越过 0.005 阈）。
- **重放**：腿 103.9→280.3，**恰止于 goal 末端，无任何后续运动**。

即：生产的异常是**冻结指令下自持的物理侧运动**，且不需要 driver
存活来维持——driver 类候选至多是"触发前因"，不是"维持者"。
