# RTF 限流重放（2026-10-20）——RTF 退化排除为充分条件

背景：四次生产失败（r10/r11/2c/prodcap）全部在末端减速窗出现 RTF 退化
（细粒度：2c 0.999→0.831→0.265；prodcap 1.000→0.505→0.284），而全部
隔离通过（2a/2b/verbatim 重放）RTF≈1。单变量检验：同一捕获 goal 的
verbatim 重放 + 强制 RTF 退化（gz 钉核 + 同核忙循环；其余与通过的
重放完全一致）。

## 结果

| run | 减速/保持窗实测 RTF | 保持 60 sim-s 结果 |
|---|---|---|
| 浅档（2 核+4 hogs） | 0.61–0.64 | max err ≤9.2e-5，斜率 ~1e-9 |
| **深档（1 核+5 hogs）** | **0.298–0.301（=生产失效深度）** | **max err ≤1.1e-4，斜率 ~1e-9** |

两档均 goal SUCCESS（586.3s wall / 177.27 sim-s @0.30）、follow 全成
（23800/23800）。**判定：RTF 退化至生产深度，在隔离链中不足以触发
异常**——生产中的 RTF 崩塌按当前证据为**效应或伴生现象**，非原因。

附带排除（离线）：prodcap 与重放捕获流中**均无任何 cancel 请求**——
"driver 等待公式墙钟到期→cancel"假设排除。
