关键读数：

1. 精确关系：**时间拉伸因子 = max(速度超限比, √加速度超限比)**
   （spline_timing_bounds.required_time_scale）。本表三腿均由加速度项绑定
   （4.71/4.25/3.73 ↔ 4.709/4.251/3.731，一一对应），速度界全程不绑定
   （≤0.98），拉伸按当前算法定义执行、无过度/欠收缩。**这只证明拉伸
   符合现行算法，不证明该计时最优**——局部尖峰导致整条腿统一减速，
   存在明显优化空间（方向 2 的研究对象）。
2. **r5 那条腿不违界**（双比率 0.99）——免责范围**仅限该条轨迹**，
   不能推广到旧计时的全部输出；违界是合并路线新增的长拼接腿
   （323/197/220 knots，多跳缝合折点）特有。支持裁定方向 2 的定义：
   **改路径/导数连续性，保留安全界与碰撞认证**（不是删界恢复速度）。
3. 几何绕行与拉伸是**独立乘子**：全路线 len 49.6 rad（r5 单腿 3.30），
   G3 计时全路线 112.6s 已含绕行；拉伸再乘至 399.8s。
   **399.8s 是认证轨迹时长**；全周期还需加规划、交接等待与其余腿的
   非 trajectory 时间（修正此前 375s 的部分和表述）。
4. staging 多候选 vs 目标梯级对"两段 PORTAL_TRANSIT+绕行"的归因
   **未定**：需要同一冻结 Select 请求的离线消融（route_producer 组件
   开关重放）——select 捕获只有 Request 侧，路线构成（节点 region 表）
   未在响应侧留证，消融实验规格待派。
