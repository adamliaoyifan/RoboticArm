LRF-P1 MuJoCo + D455 validation

Simulator: MuJoCo 3 (Isaac Lab is not installed).
Sensor: Intel RealSense D455 pinhole RGB-D, 848x480, VFOV 58 deg, IMU site unused.
Input: ONE depth frame per case, back-projected to world XYZ. Not lidar, not a bag.
Learned residual does not override a successful D455 baseline box (that was the red-box drift). Residual is only a fallback if the detector fails.
Table pixels with z<2cm are dropped (stand-in for semantic table removal).
D455 depth K uses official VFOV 58 deg at 848x480 (fx=fy=432.971). Resulting HFOV is 88.80 deg vs datasheet 87 deg.
